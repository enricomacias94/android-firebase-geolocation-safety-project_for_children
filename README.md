# Android Firebase Geolocation Safety App

## Description
This project is an Android application developed as part of a course on **Android Development**.  
It is designed to demonstrate real-time geolocation functionality using **Firebase** as the backend. The app tracks location data securely and is intended for safety-related monitoring scenarios.

> ⚠️ **Note:** To run this project, you need **Android Studio** and a **Firebase account**. The Firebase configuration file (`google-services.json`) must be added to the project for full functionality.

---

## Technologies Used
- **Java** (Android Development)
- **Android Studio**
- **Firebase Realtime Database**
- **Firebase Authentication**
- **Google Location Services**

---

## Features
- Real-time geolocation tracking
- Firebase backend integration
- Secure user authentication
- Safety-oriented design

---

## Course Context
This project was developed as part of the course **Development in Android Environment**.  
It demonstrates practical Android development skills including UI design, Firebase integration, and geolocation services.
